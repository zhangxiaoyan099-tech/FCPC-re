# FCPC reconstruction_v1 实验记录

记录日期：2026-08-26  
实验状态：已完成第一轮可运行重构；当前 FCPC 未超过 FedAvg  
用途：保存负结果、运行证据、问题诊断与下一阶段计划。本文件中的结果暂不用于论文性能主张。

## 1. 本轮结论

本轮实验确认 FCPC 训练路径可以运行，JSDN 矩阵、LDP 扰动、最大差异客户端配对、配对模型正则项和梯度传播均已实际执行。但是，在相同 ResNet-18、CIFAR-10 双偏斜划分、随机种子和训练预算下，当前重构的 FCPC 没有超过调优后的 FedAvg。

当前最保守的结论是：

> `reconstruction_v1` 是一组有效的当前实现对照实验，但不是原论文表格的严格复现。它表明当前 FCPC 实现无法支持“FCPC 必然优于 FedAvg”的原稿性能主张。

已有日志和模型不得删除，应作为负结果和后续修改的基准。后续版本必须使用新的运行名称，例如 `reconstruction_v2`，避免覆盖本轮数据。

## 6. JSDN 与客户端配对审计

### 6.1 样本数量

从 CIFAR-10 训练集划出 5000 个验证样本后，剩余 45000 个候选训练样本。当前 `quantity_skew_resample` 最终只保留 21902 个客户端训练样本：

```text
[3378, 668, 2631, 771, 1611, 2874, 4179, 832, 4822, 136]
```

这意味着：

- 丢弃了 23098 个候选训练样本，占 51.33%；
- 实际训练样本只占原始 CIFAR-10 50000 个训练样本的 43.80%；
- 最大客户端 4822 个样本，最小客户端仅 136 个样本，数量相差约 35.5 倍。

当前双偏斜同时引入了标签偏斜、数量偏斜和总训练数据减少。FedAvg 与 FCPC 使用相同数据，因此当前 A/B 对照仍然公平；但绝对准确率及跨 alpha 结果不能直接视为原论文复现。

### 6.2 原始和 LDP 后配对

原始 JSDN 贪心配对：

```text
(6, 9)  0.9247
(1, 2)  0.8463
(0, 7)  0.8392
(4, 8)  0.7820
(3, 5)  0.6665
```

LDP 后第 1 轮实际配对：

```text
(9, 5)  0.8174
(2, 3)  0.7619
(8, 7)  0.7517
(1, 0)  0.7200
(6, 4)  0.7044
```

五对客户端没有一对保持不变，但原始/LDP JSDN 矩阵相关系数仍为 0.8771。把实际配对放回原始矩阵后，其总原始 JSDN 约为 3.939；原始贪心配对总值约为 4.059。LDP 配对仍保留约 97% 的总差异强度。

结论是：LDP 会使贪心匹配组合不稳定，但实际选择的仍是高差异客户端。LDP 可能贡献性能下降，但不足以单独解释全部差距。

## 7. 当前实现可能落后 FedAvg 的原因

### 7.1 最大差异配对与参数吸引存在冲突

当前正则项为：

\[
R_{FCPC}=\|w_i^t-w_j^{t-1}\|^2,
\qquad
\nabla_{w_i}R_{FCPC}=2(w_i-w_j^{t-1}).
\]

它把当前客户端模型拉向差异最大客户端的旧参数。参数靠近并不等价于两个客户端任务梯度方向对齐。对于标签类别高度互补的客户端，配对正则梯度可能与分类梯度冲突。

### 7.2 大、小客户端之间的累计约束不对称

实际配对的数据量为：

| 配对 | 样本量 |
|---|---:|
| 9 ↔ 5 | 136 ↔ 2874 |
| 2 ↔ 3 | 2631 ↔ 771 |
| 8 ↔ 7 | 4822 ↔ 832 |
| 1 ↔ 0 | 668 ↔ 3378 |
| 6 ↔ 4 | 4179 ↔ 1611 |

相同本地 epoch 下，大客户端执行更多 batch，因此会在更多优化步骤中被拉向小客户端的旧模型；小客户端只经历少量反向更新。随后服务器又在 FedAvg 聚合中给大客户端更高权重。这可能使受约束较多的大客户端模型以较高权重进入全局聚合。

### 7.3 正则强度没有考虑客户端可靠性

JSDN 的数量项倾向于把大、小客户端配对，但所有方向统一使用相同 beta。只有 136 个样本、类别高度偏斜的客户端模型，可以与拥有数千样本的客户端模型产生相同单步约束强度。当前正则没有根据样本量、模型可靠性或配对 JSDN 调整方向和强度。

### 7.4 使用上一轮陈旧模型作为目标

客户端在第 t 轮被拉向配对客户端第 t-1 轮的本地模型。固定高差异配对会反复使用带有强本地偏置的历史目标，可能产生持续拖拽。

### 7.5 高维参数距离的尺度依赖

当前正则对 ResNet-18 全部可训练参数的距离平方求和，没有按参数数量或层归一化。beta 的有效尺度随模型大小改变。当前筛选出的 0.01 与原稿宣称的 0.2 差异很大，表明遗失实现和论文公式之间可能还存在未恢复的归一化或层选择细节。

### 7.6 LDP 引起匹配组合变化

虽然 LDP 后仍然选择高差异客户端，但五对组合全部改变。贪心匹配具有组合敏感性，矩阵中若干接近的边被扰动后会级联改变剩余配对。

### 7.7 强化后的 FedAvg 已经高于原稿基线

原稿在 CIFAR-10、`alpha=0.1` 下报告 FedAvg 65.19%。当前 FedAvg 最后一轮测试准确率达到 68.86%。CIFAR 数据增强、归一化、CIFAR-style ResNet 和优化器调优增强了基础方法。当前结果不支持 FCPC 在较强 FedAvg 基线上仍能产生原稿声称的增益。

## 10. 下一步计划

在完成以下事项前，不继续盲目运行新的 200 轮实验。

### 阶段 A：补齐实验审计信息

1. 每次运行保存客户端样本数和标签直方图；
2. 保存原始 JSDN、LDP-JSDN 和每轮实际配对；
3. 记录每个客户端每轮的 batch 数、任务损失、原始 FCPC 损失和加权 FCPC 损失；
4. 在配置和 CSV 中记录 `partition_mode`、隐私开关和 quantity-skew 生成方式；
5. 保存 Git commit、配置文件和数据划分摘要。

### 阶段 B：修正 quantity-skew 实验协议

实现一种不丢弃样本的数量偏斜方案，使全部 45000 个训练样本被不均匀分配给客户端。旧的裁减方案保留为明确命名的 ablation，不再作为默认 dual-skew。

需要保证：

- FedAvg 和 FCPC 使用完全相同的索引；
- 不同 alpha 的总训练样本数保持一致；
- 每个样本只属于一个客户端；
- 所有客户端至少有可训练样本；
- 保存划分索引或确定性摘要。

### 阶段 C：隔离 LDP 和配对影响

在同一划分、同一初始化和 30–50 轮预算下运行：

```text
FedAvg
FCPC + raw JSDN（不加LDP噪声）
FCPC + LDP JSDN（epsilon=1）
```

判定规则：

- raw JSDN 明显优于 LDP-JSDN：优先处理隐私扰动和匹配稳定性；
- 两种 FCPC 都低于 FedAvg：问题主要来自最大差异参数约束；
- 两种 FCPC 均有提升：再进入相似、随机和最优匹配消融。

### 阶段 D：检查核心配对假设

固定公共协议后比较：

```text
最大差异配对
最相似配对
随机配对
无配对（FedAvg）
```

如果相似或随机配对优于最大差异配对，则原稿“差异越大，约束越有效”的核心主张不成立或需要重写。

### 阶段 E：仅在证据支持后修改方法

以下改动属于新方法设计，不应在诊断阶段同时混入：

- 按样本量或可靠性设置方向性 beta；
- 对参数距离按参数数量或层归一化；
- 让 beta 随训练轮次衰减；
- 使用梯度或更新方向相似度代替全模型参数距离；
- 根据 JSDN 连续加权正则强度；
- 更新或动态轮换客户端配对。

这些方案必须分别进行消融，不能一次性全部修改，否则无法确定性能变化来源。
