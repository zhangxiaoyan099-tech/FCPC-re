# 安全近端 FCPC：从四项误差到可证明的漂移控制

## 1. 本文档回答的问题

本文件整理以下连续问题：

1. 最大化加权 JS 互补收益以后，为什么还不能直接宣称全局收敛更快？
2. 配对更新相对理想全局更新的四类误差是什么？
3. 缩小整体更新误差上界，代入全局递推后能得到什么结论？
4. 什么因素阻碍整体误差降低？
5. 如何修改 FCPC，使共同中心操作至少不会放大配对客户端的参数分歧？
6. 修改后的算法能够保证什么，又不能保证什么？

本文件对应的新实现称为 **Safe Proximal FCPC（安全近端 FCPC）**。它保留原有 `penalty` 更新作为消融，新增 `proximal` 更新、共同中心半径裁剪和可选安全匹配约束。

---

## 2. 已经严格成立的分布层结论

客户端 (i) 的样本权重、配对内部权重和配对混合标签分布分别为

\[
a_i=\frac{N_i}{N},\qquad
\theta_{ij}=\frac{N_i}{N_i+N_j},\qquad
q_{ij}=\theta_{ij}p_i+(1-\theta_{ij})p_j.
\]

定义加权 JS 互补收益

\[
S_{ij}=(a_i+a_j)JS_{\theta_{ij}}(p_i,p_j).
\]

对于任意客户端对，存在严格恒等式

\[
a_iKL(p_i\|\bar p)+a_jKL(p_j\|\bar p)
=S_{ij}+(a_i+a_j)KL(q_{ij}\|\bar p).
\]

因此，在一个完整匹配中，最大化

\[
\sum_{(i,j)\in M}S_{ij}
\]

等价于最小化

\[
R(M)=\sum_{(i,j)\in M}(a_i+a_j)KL(q_{ij}\|\bar p).
\]

这只能直接说明：所选客户端对的混合标签分布具有最小的总加权 KL 残差。它尚未说明独立执行多步本地 SGD 后，参数更新仍然保持这种互补性。

## 3. 四类更新误差

设第 (t) 轮开始的全局模型为 (w^t)，一对客户端的实际加权更新为

\[
\Delta_{ij}^t
=\theta_{ij}\Delta_i^t+(1-\theta_{ij})\Delta_j^t.
\]

若每个客户端执行 (E) 个本地步骤，则理想全局更新写成

\[
-\eta E\nabla F(w^t).
\]

配对更新误差为

\[
e_{ij}^t=\Delta_{ij}^t+\eta E\nabla F(w^t).
\]

它可以分解为

\[
e_{ij}^t=A_{ij}^t+B_{ij}^t+C_{ij}^t+D_{ij}^t,
\]

其中：

- (A_{ij}^t)：共同起点上的配对梯度与全局梯度偏差；
- (B_{ij}^t)：多步本地 SGD 使客户端离开共同起点产生的轨迹漂移；
- (C_{ij}^t)：mini-batch 随机梯度噪声；
- (D_{ij}^t)：共同中心正则产生的附加更新。

四项不能孤立理解。特别是 (D_{ij}^t) 的设计目的就是抵消 (B_{ij}^t)，所以真正应该比较的是

\[
\|B_{ij}^t+D_{ij}^t\|^2,
\]

而不是要求 (|D_{ij}^t|) 越小越好。

正则确实纠正漂移的充分条件为

\[
\|B+D\|^2<\|B\|^2,
\]

等价于

\[
2\langle B,D\rangle+\|D\|^2<0.
\]

因此，共同中心更新必须与漂移方向相反且强度合适。

---

## 4. 缩小整体误差能否改善全局收敛

把服务器实际方向写成

\[
\widehat g_t=\nabla F(w^t)+e_t,
\]

全局更新为

\[
w^{t+1}=w^t-\gamma\widehat g_t.
\]

若 (F) 为 (L)-smooth，取 (gamma=1/L)，则

\[
F(w^{t+1})
\le F(w^t)
-\frac{1}{2L}\|\nabla F(w^t)\|^2
+\frac{1}{2L}\|e_t\|^2.
\]

若

\[
\mathbb E_t\|e_t\|^2\le U_t,
\]

则非凸情况下有

\[
\frac1T\sum_{t=0}^{T-1}
\mathbb E\|\nabla F(w^t)\|^2
\le
\frac{2L(F(w^0)-F_{\inf})}{T}
+\frac1T\sum_{t=0}^{T-1}U_t.
\]

所以整体 (U_t) 变小可以带来：

1. 同轮数下更小的驻点误差上界；
2. 更低的误差下限；
3. 达到固定误差阈值所需的理论轮数减少。

但若 (U_t) 只是一个更小的常数，它改善的是收敛常数和误差地板，没有把 (O(1/T)) 改成更快的阶。只有进一步证明

\[
U_t\le\kappa\|\nabla F(w^t)\|^2
\]

并使 (kappa) 变小，才可以宣称改善了收缩系数。

## 5. 什么阻碍了整体误差降低

### 5.1 加权 JS 只控制第一项的代理上界

在共享类别条件分布的标签偏斜假设下，

\[
\|\nabla F_{ij}(w)-\nabla F(w)\|^2
\le 2G^2KL(q_{ij}\|\bar p).
\]

因此 (R(M)) 控制 (A) 的一个上界，但不直接控制本地轨迹、随机噪声和共同中心偏差。

### 5.2 全参与的一步梯度会与配对无关

若全部客户端在同一个 (w) 上只计算一步梯度，

\[
\sum_{(i,j)}(a_i+a_j)\nabla F_{ij}(w)=\nabla F(w).
\]

此时无论怎样配对，第一步聚合均值都相同。配对只能通过多步本地训练、部分参与和正则化轨迹产生作用。

### 5.3 互补客户端可能分离得更快

标签差异大的客户端可能具有更不一致的局部梯度。第一步以后它们位于不同参数点，原来在共同点上成立的梯度互补不再精确，导致 (B) 增大。

### 5.4 历史共同中心可能陈旧

共同中心由上一轮客户端模型构成。参数平均不等于在混合数据上训练，历史中心也不一定接近当前全局下降方向，因此 (D) 可能抵消 (B)，也可能与 (B) 同向。

### 5.5 噪声和 LDP 不由互补分数控制

小样本客户端可能具有更高梯度方差；LDP 后标签直方图还可能改变最优匹配。因此最小化带噪的 (R(M)) 不一定最小化真实更新误差。

## 6. 配对均值与配对分歧

定义

\[
m_{ij}^s=\theta w_i^s+(1-\theta)w_j^s,
\qquad
d_{ij}^s=w_i^s-w_j^s.
\]

配对均值相对真正配对目标梯度的轨迹误差为

\[
\varepsilon_{ij}^s
=\theta[\nabla L_i(w_i^s)-\nabla L_i(m_{ij}^s)]
+(1-\theta)[\nabla L_j(w_j^s)-\nabla L_j(m_{ij}^s)].
\]

若局部梯度为 (L)-Lipschitz，则

\[
\boxed{
\|\varepsilon_{ij}^s\|
\le 2L\theta(1-\theta)\|d_{ij}^s\|.
}
\]

因此，只要能够压缩 (|d_{ij}^s|)，配对均值就更接近沿 (F_{ij}) 的梯度更新。这是新优化策略的直接理论目标。

## 7. 安全近端 FCPC 算法

### 7.1 安全最大权匹配

首先计算所有边的加权 JS 互补收益 (S_{ij})。可选地，仅允许满足以下约束的边进入匹配图：

\[
\|c_{ij}^{t-1}-w^t\|\le\tau_t.
\]

然后在可行边集合中求最大权、最大基数匹配：

\[
M_t^*=\arg\max_{M\subseteq\mathcal E_t^{\mathrm{safe}}}
\sum_{(i,j)\in M}S_{ij}.
\]

如果某客户端没有安全边，它不使用 FCPC 正则，但仍进行普通本地训练并参与服务器聚合。这样不会为了完整配对而强行采用不安全中心。

在同一个可行匹配集合内，最大化互补收益仍等价于最小化总加权 KL 残差。

### 7.2 构造并裁剪共同中心

原始共同中心为

\[
c_{ij}^{t-1}
=\theta v_i^{t-1}+(1-\theta)v_j^{t-1}.
\]

将其投影到以当前全局模型为中心、半径为 (delta_t) 的球内：

\[
\widetilde c_{ij}^{t-1}
=w^t+\alpha_{ij}^t(c_{ij}^{t-1}-w^t),
\]

\[
\alpha_{ij}^t
=\min\left\{1,
\frac{\delta_t}{\|c_{ij}^{t-1}-w^t\|+\varepsilon}
\right\}.
\]

于是严格满足

\[
\boxed{
\|\widetilde c_{ij}^{t-1}-w^t\|\le\delta_t.
}
\]

### 7.3 任务更新与近端中心更新分离

客户端先执行原任务和基线算法的优化步骤：

\[
\widetilde w_i^{s+1}
=w_i^s-\eta\widehat g_i(w_i^s).
\]

然后对共同中心执行精确近端操作：

\[
w_i^{s+1}
=\arg\min_w
\left\{
\frac{1}{2\eta}\|w-\widetilde w_i^{s+1}\|^2
+\beta_t\|w-\widetilde c_{ij}^{t-1}\|^2
\right\}.
\]

闭式解为

\[
\boxed{
w_i^{s+1}
=\frac{
\widetilde w_i^{s+1}
+2\eta\beta_t\widetilde c_{ij}^{t-1}
}{1+2\eta\beta_t}.
}
\]

客户端 (j) 使用完全相同的中心、(eta_t) 和学习率，因此

\[
\boxed{
w_i^{s+1}-w_j^{s+1}
=\frac{
\widetilde w_i^{s+1}-\widetilde w_j^{s+1}
}{1+2\eta\beta_t}.
}
\]

从而

\[
\boxed{
\|w_i^{s+1}-w_j^{s+1}\|
=\frac1{1+2\eta\beta_t}
\|\widetilde w_i^{s+1}-\widetilde w_j^{s+1}\|.
}
\]

只要 (eta_t\ge0)，近端共同中心操作相对于同一任务更新后的临时模型一定压缩配对分歧，不会放大分歧。

### 7.4 衰减正则

继续使用

\[
\beta_t
=\beta_{\min}
+\frac12(\beta_0-\beta_{\min})
\left(1+\cos\frac{\pi t}{T-1}\right).
\]

取 (eta_{\min}=0) 时，训练后期共同中心影响消失，降低陈旧中心造成的渐近偏差。

### 7.5 服务器聚合

本地训练完成后仍执行样本加权 FedAvg：

\[
w^{t+1}=\sum_i\frac{N_i}{N}w_i^{t,E}.
\]

并保存本轮客户端状态作为下一轮共同中心的历史输入。

## 8. 算法伪代码

```text
输入：客户端数据 Di，轮数 T，本地步数 E，初始 beta0
初始化：全局模型 w0；客户端历史 vi^-1 = w0

for t = 0, ..., T-1:
    1. 收集或读取客户端标签元数据和样本数
    2. 计算每条边的加权 JS 互补收益 Sij
    3. 根据未裁剪中心距离构造安全边集合 Esafe
    4. 在 Esafe 上求最大权、最大基数匹配 Mt

    for 每个配对 (i,j) in Mt:
        theta = Ni / (Ni + Nj)
        c_raw = theta * vi^(t-1) + (1-theta) * vj^(t-1)
        c_safe = ProjectToBall(c_raw, center=wt, radius=delta_t)

        初始化 wi^0 = wj^0 = wt
        for s = 0, ..., E-1:
            ui = TaskOptimizerStep(wi^s, batch_i)
            uj = TaskOptimizerStep(wj^s, batch_j)

            wi^(s+1) = (ui + 2*eta*beta_t*c_safe)/(1+2*eta*beta_t)
            wj^(s+1) = (uj + 2*eta*beta_t*c_safe)/(1+2*eta*beta_t)

    未配对客户端执行普通本地训练，不使用 FCPC 近端步骤
    wt+1 = SampleWeightedFedAvg({wi^E})
    vi^t = wi^E
```

## 9. 代码实现与配置

相关实现：

- `src/fcpc/regularizer.py`
  - `proximal_center_step`：精确共同中心近端映射；
  - `clip_state_center_to_global`：中心球投影；
  - `state_l2_distance`、`state_l2_norm`：参数空间审计。
- `src/fcpc/pairing.py`
  - 最大权匹配支持 `feasible_mask`，不安全边不会进入匹配图。
- `src/federated/client.py`
  - `fcpc_update_rule="penalty"`：保留旧版；
  - `fcpc_update_rule="proximal"`：任务优化后执行近端步骤。
- `src/federated/trainer.py`
  - 读取近端模式、中心裁剪和安全匹配配置；
  - 记录中心距离、裁剪比例和安全边数量。

示例配置：`configs/cifar10_safe_proximal_fcpc.yaml`。

核心字段：

```yaml
fcpc:
  metric: pair_complementarity
  reference_strategy: pair_center
  update_rule: proximal
  beta: 0.2
  beta_schedule: cosine
  min_beta: 0.0
  pairing_strategy: optimal
  center_max_relative_distance: 0.05
  pairing_max_center_relative_distance: 0.10
```

两个相对半径是待消融的初始实验值，不是理论最优值：

- `center_max_relative_distance=0.05` 表示裁剪后中心离当前全局模型不超过全局参数范数的 5%；
- `pairing_max_center_relative_distance=0.10` 表示原始中心距离超过 10% 的边不参与安全匹配。

## 10. 新策略实现的目标

### 10.1 严格实现的目标

1. **近端步骤不放大配对分歧**

   \[
   \|d_{ij}^{s+1}\|
   =\frac1{1+2\eta\beta_t}
   \|\widetilde d_{ij}^{s+1}\|.
   \]

2. **共同中心滞后距离有确定上界**

   \[
   \|\widetilde c_{ij}^{t-1}-w^t\|\le\delta_t.
   \]

3. **不安全边不会被强行采用**：没有安全伙伴的客户端退化为普通本地训练，而不是被删除。

4. **渐近中心偏差可消失**：当 (eta_t\to0) 时，近端中心的直接影响趋于零。

5. **保留加权 JS 的分布解释**：在安全可行集合内，最大化总互补收益仍最小化总加权 KL 残差。

6. **不增加每个 batch 的客户端间通信**：近端步骤使用每轮开始时已经获得的冻结中心在本地闭式计算。

### 10.2 希望通过实验验证的目标

1. 降低多步本地训练后的客户端漂移；
2. 使配对聚合更新更接近全局梯度更新；
3. 降低固定准确率所需通信轮数；
4. 避免固定大 beta 在后期损害最终精度；
5. 比原惩罚式共同中心对学习率和 beta 更稳定。

## 11. 新策略仍然存在的不足

1. **不能保证最终优于 FedAvg。** 近端操作只保证压缩两个临时模型之间的分歧，不保证压缩后的共同方向一定比 FedAvg 更接近全局最优方向。

2. **不能保证整体四项误差必然降低。** 加权 JS 控制配对梯度偏差，近端步骤控制参数分歧，中心裁剪控制滞后半径，但随机噪声和不同误差项之间的交叉项仍可能抵消或放大。

3. **标签偏斜理论不自动覆盖特征偏斜。** 如果 (P_i(x\mid y)) 不同，则 (q_{ij}\approx\bar p) 不足以保证梯度接近。

4. **安全匹配增加服务器计算成本。** 若对所有候选边计算模型中心距离，复杂度约为 (O(K^2P))，其中 (P) 是参数量；大规模客户端需要先按标签分数筛选候选边或使用低维更新摘要。

5. **安全约束可能产生更多未配对客户端。** 这是为了不违反安全半径而作出的保守选择，可能降低 FCPC 的覆盖率。

6. **半径和 beta 仍需调参。** `0.05`、`0.10` 和 `beta=0.2` 都只是实验起点，不是理论最优值。

7. **参数空间平均仍不等于混合数据训练。** 中心裁剪只能限制错误影响的最大范围，不能证明共同中心就是 (F_{ij}) 的最优点。

8. **当前保证不是完整的全局收敛定理。** 还需将配对分歧上界、中心偏差、部分参与、LDP 错配和随机噪声统一代入服务器跨轮递推。

9. **真实系统的隐私假设需要说明。** 安全匹配如果使用客户端历史模型距离，需要服务器持有模型或受保护的低维距离摘要；它不能被描述为零信息开销。

## 12. 必须进行的消融

至少比较以下组别，并固定数据划分、初始化、参与客户端、学习率和随机种子：

| 组别 | 更新形式 | 中心裁剪 | 安全匹配 | 目的 |
|---|---|---|---|---|
| FedAvg | 无 | 无 | 无 | 基准 |
| 原共同中心 | penalty | 无 | 无 | 当前算法 |
| 近端中心 | proximal | 无 | 无 | 检验近端更新 |
| 近端+裁剪 | proximal | 有 | 无 | 检验中心滞后控制 |
| 完整安全近端FCPC | proximal | 有 | 有 | 完整方法 |
| 随机配对近端 | proximal | 相同 | 无 | 隔离加权JS作用 |
| 相似配对近端 | proximal | 相同 | 无 | 检验互补配对方向 |

至少记录：

1. 总加权 KL 残差 (R(M_t))；
2. 配对参数分歧的近端前后比值；
3. 原始中心距离和裁剪比例；
4. 本地漂移 (|w_i^{t,E}-w^t|)；
5. 配对更新和全局聚合更新的余弦方向；
6. 训练损失、验证准确率、测试准确率；
7. 达到固定准确率所需轮数；
8. 配对与安全边计算时间；
9. 至少 3 个随机种子的均值和标准差。

只有在“KL 残差下降—配对轨迹误差下降—全局更新误差下降—实际轮数减少”形成一致证据后，才能把该策略描述为实际加速收敛。

## 13. 当前最准确的论文表述

可以严格陈述：

> Safe Proximal FCPC 在安全可行边集合中最大化加权 JS 互补收益，并使用精确近端映射压缩配对客户端任务更新后的参数分歧。共同中心被限制在当前全局模型的预设半径内，且衰减正则使其渐近影响消失。在标签偏斜和梯度光滑条件下，这些机制分别控制配对分布残差、配对轨迹分歧和中心滞后偏差。

暂时不能陈述：

> 这些局部保证已经证明 Safe Proximal FCPC 必然比 FedAvg 收敛更快或获得更高最终准确率。

完整结论仍取决于整体更新误差的跨轮上界以及公平消融实验。
