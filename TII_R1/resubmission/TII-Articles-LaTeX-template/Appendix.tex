\section{Nonconvex Optimization Analysis of FCPC}

\subsection{Scope of the Revised Analysis}

This appendix replaces the previous convergence proof with an analysis that
matches the implemented FCPC update. We make four boundaries explicit.
First, the objectives used by the deep models are allowed to be nonconvex;
neither strong convexity nor a contraction in distance to an unknown optimum
is assumed. Second, local differential privacy (LDP) is applied only to the
label histogram and sample-count metadata used for pairing, not to stochastic
gradients. Third, JSDN determines the partner reference but is not assumed to
be linearly related to gradient dissimilarity. Finally, the analysis does not
assign a favorable sign to the partner-reference cross term. Its sign is a
property to be measured, not a consequence of a large JSDN value.

These changes separate two questions. The optimization result below shows
when the actual FCPC update approaches a stationary point of the global
objective. The controlled pairing ablation tests whether the particular
JSDN-based choice of reference improves finite-round learning relative to
random and similarity-based references.

\subsection{Algorithmic Update and Notation}

To expose the effect of the FCPC term without conflating it with optimizer
state, we first write the local-SGD instantiation. The global descent lemma and
Theorem~\ref{thm:finite-round} only require the realized server direction and
therefore also apply when momentum is used, by defining that direction from
the net server displacement. Lemma~\ref{lem:pullback} and the explicit bound
\eqref{eq:fcpc-bias-bound} describe the momentum-free local-SGD
instantiation; they are not presented as an exact momentum recursion.

Let $F_i:\mathbb{R}^d\rightarrow\mathbb{R}$ be client $i$'s local objective
and let
\begin{equation}
 F(\bm w)=\sum_{i=1}^{K}p_iF_i(\bm w),
 \qquad p_i\geq0,\quad \sum_{i=1}^{K}p_i=1
\end{equation}
be the full-client objective. At round $t$, the server samples a participating
set $S_t$. Its normalized aggregation weights are denoted by $a_i^t$, where
$a_i^t\geq0$ and $\sum_{i\in S_t}a_i^t=1$. Let $m_i^t=1$ for a paired client
and $m_i^t=0$ for the unmatched client, if one exists. Client $i$ starts from
the current global model and performs $H$ local steps:
\begin{align}
 \bm w_{i,0}^{t}&=\bm w^t,\\
 \bm w_{i,s+1}^{t}
 &=\bm w_{i,s}^{t}-\eta_t\left[
 \bm g_i(\bm w_{i,s}^{t};\xi_{i,s}^{t})
 +2\beta_t m_i^t(\bm w_{i,s}^{t}-\bm r_i^t)\right],
 \quad 0\leq s<H.                                      \label{eq:local-update}
\end{align}
Here $\bm r_i^t$ is the paired client's previous-round model, frozen before
the current local updates begin. In the first round, the unavailable history
is replaced by the common initialization. An unmatched client still trains
and is aggregated, but $m_i^t=0$ removes its paired penalty in that round.

The server aggregation is
\begin{equation}
 \bm w^{t+1}=\sum_{i\in S_t}a_i^t\bm w_{i,H}^{t}.
\end{equation}
Define the effective round step size $\gamma_t=H\eta_t$ and the averaged
direction
\begin{equation}
 \bm U_t=\frac{1}{H}\sum_{s=0}^{H-1}\sum_{i\in S_t}a_i^t
 \left[\bm g_i(\bm w_{i,s}^{t};\xi_{i,s}^{t})
 +2\beta_t m_i^t(\bm w_{i,s}^{t}-\bm r_i^t)\right].      \label{eq:round-direction}
\end{equation}
For this local-SGD instantiation, the server update has the exact form
\begin{equation}
 \bm w^{t+1}=\bm w^t-\gamma_t\bm U_t.                    \label{eq:server-update}
\end{equation}
More generally, including momentum or another base optimizer, we define
$\bm U_t=(\bm w^t-\bm w^{t+1})/\gamma_t$; all results from
Lemma~\ref{lem:one-round} onward remain unchanged.

Let $\mathcal F_t$ contain all randomness revealed before round $t$, including
$\bm w^t$ and the frozen references, and write
$\mathbb E_t[\cdot]=\mathbb E[\cdot\mid\mathcal F_t]$.
The mean direction error and conditional variance of the complete implemented
round are
\begin{align}
 \bm b_t&=\mathbb E_t[\bm U_t]-\nabla F(\bm w^t),          \label{eq:bias-def}\\
 v_t&=\mathbb E_t\left\|\bm U_t-\mathbb E_t[\bm U_t]\right\|_2^2.
                                                                  \label{eq:variance-def}
\end{align}
The vector $\bm b_t$ includes local drift, any bias caused by client sampling
and normalized aggregation, and the paired regularizer. Defining it for the
complete round avoids silently treating those effects as zero-mean noise.

\subsection{Standard Assumptions}

\begin{assumption}[Smooth nonconvex objective]
Every $F_i$ is differentiable and $L$-smooth, and the global objective is
bounded below by $F_{\inf}>-\infty$.
\end{assumption}

\begin{assumption}[Stochastic-gradient oracle]
For every client and local iterate,
\begin{align}
 \mathbb E[\bm g_i(\bm w;\xi)\mid\bm w]&=\nabla F_i(\bm w),\\
 \mathbb E\|\bm g_i(\bm w;\xi)-\nabla F_i(\bm w)\|_2^2&\leq\sigma^2.
\end{align}
The theorem below uses the conditional round variance $v_t$, which also
captures client-sampling randomness and the dependence generated by multiple
local steps.
\end{assumption}

No assumption connects JSDN to $\|\nabla F_i-\nabla F_j\|$. Such a bridge
would require additional restrictions on the joint data distributions, for
example pure label shift with shared class-conditional distributions, which
are not imposed on the main experiments.

\subsection{What the Quadratic Penalty Provably Does}

Let $\bm d_{i,s}^{t}=\bm w_{i,s}^{t}-\bm w^t$. Subtracting $\bm w^t$ from
both sides of \eqref{eq:local-update} gives the following exact recursion.

\begin{lemma}[Pullback and partner-offset decomposition]                 \label{lem:pullback}
For every paired local step,
\begin{equation}
 \bm d_{i,s+1}^{t}
 =(1-2\eta_t\beta_t)\bm d_{i,s}^{t}
 -\eta_t\bm g_i(\bm w_{i,s}^{t};\xi_{i,s}^{t})
 -2\eta_t\beta_t(\bm w^t-\bm r_i^t).                  \label{eq:pullback-recursion}
\end{equation}
If $0\leq2\eta_t\beta_t\leq1$, then
\begin{equation}
 \|\bm d_{i,s+1}^{t}\|_2
 \leq(1-2\eta_t\beta_t)\|\bm d_{i,s}^{t}\|_2
 +\eta_t\|\bm g_i(\bm w_{i,s}^{t};\xi_{i,s}^{t})\|_2
 +2\eta_t\beta_t\|\bm w^t-\bm r_i^t\|_2.             \label{eq:pullback-bound}
\end{equation}
\end{lemma}

\begin{proof}
Use the identity
\begin{equation}
 \bm w_{i,s}^{t}-\bm r_i^t
 =(\bm w_{i,s}^{t}-\bm w^t)+(\bm w^t-\bm r_i^t)
\end{equation}
inside \eqref{eq:local-update}. Equation
\eqref{eq:pullback-recursion} follows by collecting
$\bm d_{i,s}^{t}$, and \eqref{eq:pullback-bound} follows from the triangle
inequality and $1-2\eta_t\beta_t\geq0$.
\end{proof}

For a global anchor, $\bm r_i^t=\bm w^t$, so the final term in
\eqref{eq:pullback-recursion} vanishes and the coefficient
$1-2\eta_t\beta_t$ directly contracts accumulated local drift before the next
task-gradient step. For a historical partner reference, the same pullback is
present, but it is accompanied by the offset
$-2\eta_t\beta_t(\bm w^t-\bm r_i^t)$. The offset is a descent contribution
at the beginning of the local trajectory only when
\begin{equation}
 \left\langle\nabla F(\bm w^t),\bm w^t-\bm r_i^t\right\rangle>0.          \label{eq:partner-sign}
\end{equation}
Neither a large JSDN nor the quadratic penalty alone guarantees
\eqref{eq:partner-sign}. Thus Lemma~\ref{lem:pullback} proves parameter
pullback, not unconditional gradient alignment or unconditional acceleration.

\subsection{Single-Round Descent}

\begin{lemma}[Conditional one-round descent]                             \label{lem:one-round}
Under Assumption 1, the update \eqref{eq:server-update} satisfies
\begin{align}
 \mathbb E_t F(\bm w^{t+1})
 \leq{}&F(\bm w^t)-\gamma_t\|\nabla F(\bm w^t)\|_2^2
 -\gamma_t\langle\nabla F(\bm w^t),\bm b_t\rangle \nonumber\\
 &+\frac{L\gamma_t^2}{2}
 \left(\|\nabla F(\bm w^t)+\bm b_t\|_2^2+v_t\right).   \label{eq:exact-one-round}
\end{align}
If $0<\gamma_t\leq1/(4L)$, then
\begin{equation}
 \mathbb E_t F(\bm w^{t+1})
 \leq F(\bm w^t)
 -\frac{\gamma_t}{4}\|\nabla F(\bm w^t)\|_2^2
 +\frac{3\gamma_t}{4}\|\bm b_t\|_2^2
 +\frac{L\gamma_t^2}{2}v_t.                            \label{eq:robust-one-round}
\end{equation}
\end{lemma}

\begin{proof}
By $L$-smoothness and \eqref{eq:server-update},
\begin{equation}
 F(\bm w^{t+1})
 \leq F(\bm w^t)-\gamma_t\langle\nabla F(\bm w^t),\bm U_t\rangle
 +\frac{L\gamma_t^2}{2}\|\bm U_t\|_2^2.
\end{equation}
Taking conditional expectation, using
$\mathbb E_t\bm U_t=\nabla F(\bm w^t)+\bm b_t$, and applying the
bias--variance identity gives \eqref{eq:exact-one-round}. Next use
\begin{align}
 -\langle\nabla F,\bm b_t\rangle
 &\leq\frac12\|\nabla F\|_2^2+\frac12\|\bm b_t\|_2^2,\\
 \|\nabla F+\bm b_t\|_2^2
 &\leq2\|\nabla F\|_2^2+2\|\bm b_t\|_2^2.
\end{align}
The coefficient of $\|\nabla F\|^2$ is at most
$-\gamma_t/2+L\gamma_t^2\leq-\gamma_t/4$, while the coefficient of
$\|\bm b_t\|^2$ is at most
$\gamma_t/2+L\gamma_t^2\leq3\gamma_t/4$. This proves
\eqref{eq:robust-one-round}.
\end{proof}

Equation \eqref{eq:exact-one-round} retains the cross term that was omitted in
the previous proof. It shows why comparing FCPC with FedAvg cannot be reduced
to comparing loss values or the magnitude of JSDN: the sign and magnitude of
$\langle\nabla F,\bm b_t\rangle$, as well as the second-order cost and round
variance, must all be controlled.

\subsection{Finite-Round Nonconvex Convergence}

\begin{theorem}[Finite-round stationarity bound]                          \label{thm:finite-round}
Suppose Assumption 1 holds, $0<\gamma_t\leq1/(4L)$, and the quantities in
\eqref{eq:bias-def}--\eqref{eq:variance-def} are finite. For every $T\geq1$,
\begin{align}
 \frac{\sum_{t=0}^{T-1}\gamma_t
 \mathbb E\|\nabla F(\bm w^t)\|_2^2}
 {\sum_{t=0}^{T-1}\gamma_t}
 \leq{}&
 \frac{4\left[F(\bm w^0)-F_{\inf}\right]}
 {\sum_{t=0}^{T-1}\gamma_t} \nonumber\\
 &+\frac{3\sum_{t=0}^{T-1}\gamma_t
 \mathbb E\|\bm b_t\|_2^2}
 {\sum_{t=0}^{T-1}\gamma_t}
 +\frac{2L\sum_{t=0}^{T-1}\gamma_t^2\mathbb E v_t}
 {\sum_{t=0}^{T-1}\gamma_t}.                           \label{eq:finite-round-bound}
\end{align}
\end{theorem}

\begin{proof}
Take total expectation in \eqref{eq:robust-one-round}, sum it from $t=0$ to
$T-1$, and telescope the objective values. Use
$\mathbb E F(\bm w^T)\geq F_{\inf}$ and divide by
$\frac14\sum_{t=0}^{T-1}\gamma_t$.
\end{proof}

For a constant $\gamma_t=\gamma$, if
$\mathbb E\|\bm b_t\|^2\leq B^2$ and $\mathbb E v_t\leq V$, then
\begin{equation}
 \frac1T\sum_{t=0}^{T-1}\mathbb E\|\nabla F(\bm w^t)\|_2^2
 \leq\frac{4[F(\bm w^0)-F_{\inf}]}{\gamma T}
 +3B^2+2L\gamma V.                                      \label{eq:constant-step-bound}
\end{equation}
Thus a fixed nonvanishing direction bias generally gives convergence only to
a stationary neighborhood. This is relevant to a fixed partner penalty: a
historical reference that remains separated from the current global model
cannot be omitted from the limiting error.

\begin{corollary}[Convergence to stationarity]
If $\sum_t\gamma_t=\infty$, $\sum_t\gamma_t^2<\infty$,
$\sup_t\mathbb E v_t<\infty$, and
\begin{equation}
 \frac{\sum_{t=0}^{T-1}\gamma_t\mathbb E\|\bm b_t\|_2^2}
 {\sum_{t=0}^{T-1}\gamma_t}\longrightarrow0,
\end{equation}
then the weighted average of
$\mathbb E\|\nabla F(\bm w^t)\|_2^2$ converges to zero.
\end{corollary}

The corollary can be satisfied by a diminishing $\beta_t$ together with
vanishing local drift and sampling bias, or by references whose displacement
from the current global model vanishes sufficiently quickly. The theorem
does not claim exact stationarity for a fixed $\beta$ and a persistently stale
partner.

\subsection{Where the FCPC Reference Enters the Bound}

The following quantities make the role of the reference explicit without
postulating a JSDN--gradient law:
\begin{align}
 D_t^2
 &=\mathbb E_t\left[\frac1H\sum_{s=0}^{H-1}
 \sum_{i\in S_t}a_i^t\|\bm w_{i,s}^{t}-\bm w^t\|_2^2\right],\\
 A_t^2
 &=\mathbb E_t\left[\sum_{i\in S_t}a_i^t
 m_i^t\|\bm w^t-\bm r_i^t\|_2^2\right],\\
 \bm\chi_t
 &=\mathbb E_t\left[\sum_{i\in S_t}a_i^t
 \nabla F_i(\bm w^t)\right]-\nabla F(\bm w^t).
\end{align}
$D_t$ is local drift, $A_t$ is reference staleness, and $\bm\chi_t$ records
any mismatch caused by the actual sampling and aggregation rule. By
$L$-smoothness and Jensen's inequality,
\begin{equation}
 \|\bm b_t\|_2^2
 \leq3L^2D_t^2+3\|\bm\chi_t\|_2^2
 +24\beta_t^2(D_t^2+A_t^2).                             \label{eq:fcpc-bias-bound}
\end{equation}
Indeed, the task-gradient drift has squared norm at most $L^2D_t^2$, while
the regularizer contribution has squared norm at most
\begin{align}
 &4\beta_t^2\mathbb E_t\left[\frac1H\sum_{s=0}^{H-1}
 \sum_{i\in S_t}a_i^tm_i^t
 \|\bm w_{i,s}^{t}-\bm r_i^t\|_2^2\right]\\
 &\qquad\leq8\beta_t^2(D_t^2+A_t^2).
\end{align}
Applying $\|\bm x+\bm y+\bm z\|^2\leq
3(\|\bm x\|^2+\|\bm y\|^2+\|\bm z\|^2)$ yields
\eqref{eq:fcpc-bias-bound}.

\begin{corollary}[Sufficient conditions for FCPC stationarity]
Suppose the conditions of Theorem~\ref{thm:finite-round} hold,
$\sum_t\gamma_t=\infty$, $\sum_t\gamma_t^2<\infty$, and
$\sup_t\mathbb E v_t<\infty$. If
\begin{equation}
 \frac{\sum_{t=0}^{T-1}\gamma_t\mathbb E\!\left[
 (L^2+8\beta_t^2)D_t^2+\|\bm\chi_t\|_2^2
 +8\beta_t^2A_t^2\right]}
 {\sum_{t=0}^{T-1}\gamma_t}\longrightarrow0,            \label{eq:fcpc-sufficient}
\end{equation}
then
\begin{equation}
 \frac{\sum_{t=0}^{T-1}\gamma_t
 \mathbb E\|\nabla F(\bm w^t)\|_2^2}
 {\sum_{t=0}^{T-1}\gamma_t}\longrightarrow0.
\end{equation}
\end{corollary}

This follows directly from \eqref{eq:fcpc-bias-bound} and the stationarity
corollary above. Condition \eqref{eq:fcpc-sufficient} exposes rather than
hides the required FL controls: local drift must vanish on average, the
sampling/aggregation rule must become unbiased on average, and the
regularization-weighted reference staleness must vanish. For example, the
last requirement can hold when the references approach the global model or
when $\beta_t$ decreases sufficiently quickly. A fixed $\beta$ with a
persistently stale partner is not covered by an exact-stationarity claim.

For a global anchor, $A_t=0$ and Lemma~\ref{lem:pullback} explains how the
penalty can reduce $D_t$. For a historical partner, the same stabilizing
pullback remains, but $A_t$ is generally nonzero and the signed condition
\eqref{eq:partner-sign} is not guaranteed. This decomposition is consistent
with the single-seed 50-round mechanism screening: the global-anchor treatment
provided the clearest reduction in update dispersion and the largest observed
AUC gain, whereas the high-JSDN, random, and low-JSDN partner treatments did
not establish a persistent ordering in AUC at 50 rounds. The screening result
motivates the decomposition; it is not used as a substitute for the proof or
as a claim of statistical significance.

Consequently, JSDN does not appear as a favorable term in
\eqref{eq:finite-round-bound}. A JSDN-based reference can improve the bound
only indirectly, by empirically reducing the realized drift, reference error,
sampling mismatch, or variance, or by producing a favorable cross term in
\eqref{eq:exact-one-round}. These mechanisms must be evaluated directly.

\section{Definition and Basic Properties of JSDN}

Let $\bm p_i,\bm p_j\in\Delta^{C-1}$ be label distributions and let
$N_i,N_j>0$ be sample counts. With base-two logarithms, define
\begin{align}
 \JSD(\bm p_i,\bm p_j)
 &=\frac12D_{\mathrm{KL}}(\bm p_i\Vert\bm m_{ij})
 +\frac12D_{\mathrm{KL}}(\bm p_j\Vert\bm m_{ij}),\\
 \bm m_{ij}&=\frac{\bm p_i+\bm p_j}{2},\\
 q_{ij}&=\frac{|N_i-N_j|}{N_i+N_j},\\
 \JSDN_{ij}&=(1-\lambda)\JSD(\bm p_i,\bm p_j)+\lambda q_{ij},
 \qquad \lambda\in[0,1].
\end{align}

\begin{proposition}[Boundedness, symmetry, and single-skew reduction]
For every valid pair, $\JSDN_{ij}=\JSDN_{ji}$ and
$0\leq\JSDN_{ij}\leq1$. If $0<\lambda<1$, then
$\JSDN_{ij}=0$ if and only if the clients have identical label distributions
and equal sample counts. Under equal sample counts, JSDN and JSD induce the
same pair ranking; under equal label distributions, JSDN and $q_{ij}$ induce
the same pair ranking.
\end{proposition}

\begin{proof}
Base-two JSD and $q_{ij}$ are symmetric and belong to $[0,1]$, so their convex
combination has the same properties. For $0<\lambda<1$, the convex
combination is zero exactly when both nonnegative components are zero. At
either single-skew limit, the remaining nonzero component is multiplied by a
positive constant, which preserves its ranking.
\end{proof}

These properties show that JSDN is a normalized composite metadata measure;
they do not prove that a larger JSDN yields a more useful optimization
direction. The weight $\lambda=0.3$ is therefore reported as an empirical
choice over the tested search range, not as a universal theoretical optimum.

\section{Pairing Rule and Odd-Client Handling}

FCPC greedily selects a currently available edge with a large JSDN score and
removes its two endpoints until fewer than two clients remain. We describe
this rule as a dissimilarity-seeking heuristic. We do not use a
maximum-weight-matching approximation ratio as evidence of learning quality:
maximizing the sum of metadata dissimilarities is not itself a convergence or
accuracy objective. Its optimization value is assessed against random and
similarity-based pairing under common partitions, client samples, and seeds.

When the number of participating clients is odd, the unmatched client is not
discarded. It performs the ordinary local task update, participates in server
aggregation, and simply receives no paired penalty in that round. A fair-bye
counter rotates this status among clients so that an always-participating
client is not systematically excluded from regularization.

\section{Complexity and Communication Accounting}

For $n=|S_t|$ participating clients, $C$ classes, and a model state containing
$P_b$ bytes, constructing the dense JSDN matrix costs $O(n^2C)$ arithmetic and
$O(n^2)$ storage. Sorting all candidate edges and scanning them greedily
costs $O(n^2\log n)$ time and $O(n^2)$ storage. Computing the quadratic
penalty adds $O(P)$ arithmetic per mini-batch over $P$ trainable parameters
and requires one frozen reference state.

FCPC does not add server communication rounds, but a full-model partner
implementation adds partner-model traffic. With an even participating set,
the model payload is $3nP_b$ per round for FCPC versus $2nP_b$ for FedAvg:
$nP_b$ for global downloads, $nP_b$ for server uploads, and an additional
$nP_b$ for partner references. This 50\% model-payload increase is measured
and reported rather than called negligible.

\section{Threat Model}

The statistical analysis assumes honest-but-curious clients and an
authenticated server. Metadata LDP does not make the method robust to a
malicious client that sends a poisoned partner model. Because FCPC retains
the base server aggregator, it can in principle be combined with robust
aggregation or anomaly detection, but both server-bound and partner-bound
states must then be filtered. No Byzantine-robustness claim follows from
dissimilarity-aware pairing alone.
